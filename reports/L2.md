# L2 — unlocked combinations: experts sharded by FSDP (efsdp > 1) and HSDP + EP

Only one 8-GPU node is available, so the 16-rank scenarios of DESIGN §6-L2 are run as the
structurally identical 8-rank topologies listed in `reports/decisions.md` (D10); the exact
16/64-rank mesh shapes are pinned by the fake-PG L0 tests
(`tests/model/test_decoupled_ep_fsdp_mesh.py::TestDecoupledMoEMeshShapes`,
`::TestDecoupledMoEParamPlacements::test_param_placements_with_hsdp`).

```bash
PYTHONPATH=. torchrun --nproc-per-node 8 tests/model/run_decoupled_ep_fsdp_numerics.py \
    --modes A:ep=1 B4:ep=4 C4:ep=4,decouple=1 H41:ep=4,decouple=1,hsdp=4 B2:ep=2 H22:ep=2,decouple=1,hsdp=4 \
    --steps 50 --out l2.json
python tests/model/summarize_decoupled_ep_fsdp_numerics.py l2.json --ref B4
```

Same tiny Qwen3-MoE, data, optimizer and precision settings as `reports/L1.md`.

| mode | config | root mesh | what it exercises |
|---|---|---|---|
| A | `ep=1` | FSDP-8 | baseline |
| B4 | `ep=4` (legacy) | `(fsdp=2, ep=4)` | legacy reference for C4 / H41 |
| C4 | `ep=4, decouple` | `(1, efsdp=2, ep=4)` | **experts also FSDP-sharded**: `(_StridedShard(0, sf=4), Shard(0))` on `(efsdp, ep)` — the 16-rank `ep=8, dp_shard=16` structure |
| H41 | `ep=4, decouple, hsdp_sharding_size=4` | `(replicate=2, efsdp=1, ep=4)` | **the formerly asserted HSDP + EP combination** — the 16-rank `ep=8, hsdp_sharding_size=8` structure |
| B2 | `ep=2` (legacy) | `(fsdp=4, ep=2)` | legacy reference for H22 |
| H22 | `ep=2, decouple, hsdp_sharding_size=4` | `(replicate=2, efsdp=2, ep=2)` | replicate > 1 **and** efsdp > 1 at the same time |

## Result summary

- **Loss**: every decoupled mode matches its legacy reference within the bf16 noise floor:
  C4 vs B4 `2.0e-5`, H41 vs B4 `2.2e-5`, H22 vs B4 `1.6e-5` (max rel diff over 50 steps), while the
  legacy-vs-legacy pairs give A vs B4 `1.5e-5` and B2 vs B4 `3.0e-5`.
- **Per-parameter grad norms at step 0**: expert params ≤ `3.1e-5`, dense params ≤ `1.5e-3` for all
  decoupled modes — same order as the legacy-vs-legacy pairs (`2.1e-5` / `2.9e-3`).
- **Memory**: C4 stores 3.6 MiB of dense params per rank (B4: 14.3 MiB = 4× replication); H41/H22
  store 7.1 MiB (dp_shard = 4) and 96 MiB of experts (replicated twice across the two HSDP replicas,
  as configured).
- **Step time**: all decoupled modes within ±2 ms of their legacy reference on this
  launch-overhead-bound tiny model (C4 84.9 vs B4 83.8; H41 78.8; H22 85.1 vs B2 82.4).
